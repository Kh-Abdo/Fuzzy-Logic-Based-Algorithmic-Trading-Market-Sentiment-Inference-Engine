Inference pipeline

Mamdani inference in five stages

  1. 1Fuzzify
  2. 2Evaluate
  3. 3Aggregate
  4. 4Defuzzify
  5. 5Signal

Fuzzification

Each input gets a degree between 0 and 1 in every linguistic set.

Appears when the analysis runs.

Rule evaluation

Nine rules pair an RSI set with a sentiment set. AND takes the smaller degree.

Appears when the analysis runs.

Aggregation

Each output set is cut at its rule strength, then the cuts are merged with MAX.

Appears when the analysis runs.

Defuzzification

The centre of gravity of the merged shape becomes one number.

Appears when the analysis runs.

Execution signal

The score is read against the five execution zones.

Appears when the analysis runs.

Mamdani inference with MIN for AND, MAX for aggregation and centroid defuzzification sampled every 0.5 points. Educational model, not investment advice.
